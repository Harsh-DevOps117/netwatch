# Netwatch - Frontend Application

This directory contains the frontend portion of the Netwatch project, a web interface for predicting and visualizing network attacks using AI World Models.

## Overview

The frontend is designed with a brutalist aesthetic, drawing inspiration from modern web design standards (like Awwwards). It provides the interface for:
* Visualizing the output of our GNN / TFT network models.
* Displaying real-time risk scores and threat forecasts on a comprehensive dashboard.
* Proposing automated countermeasures for detected threats.

## Technologies Used

* Next.js (React)
* Tailwind CSS for styling
* GSAP for scroll animations and transitions

## Setup Instructions

To run the frontend application locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
